# Week 1 – Excel Data Analysis

## 📌 Project Overview
This project was completed as part of my Data Analyst Internship – Week 1 task.

The objective was to analyze and clean a sales dataset using Microsoft Excel and create meaningful insights using Excel's data analysis features.

## 🛠️ Tools Used
- Microsoft Excel
- Pivot Tables
- Excel Formulas
- Conditional Formatting
- Bar Charts
- Data Cleaning

## 📋 Tasks Completed

### 1. Data Cleaning
- Removed duplicate records.
- Checked the dataset for missing values.
- Verified the data for consistency.

### 2. Region-wise Sales Analysis
Created a Pivot Table to calculate total sales for each region.

### 3. Statistical Analysis
Calculated:
- Mean
- Median
- Mode

using the Sales column.

### 4. Top 10 Sales
Used Conditional Formatting to highlight the top 10 sales values.

### 5. Category-wise Revenue
Created a Pivot Table and Bar Chart to analyze revenue by product category.
